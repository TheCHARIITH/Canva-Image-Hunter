<h1 align="center">Canva Image Hunter 🖼️</h1>

<p align="center">
  <strong>Unlock and re-use any Canva Pro image or element in your own designs.</strong>
</p>

---
</br>

## ✨ Features

* **🔓 Unlock Pro Assets:** Get direct access to **Canva Pro images** and elements that are normally restricted.
* **✨ Instant Re-use:** Copy the image as a **PNG** to paste it directly into your new design, another app, or a document.
* **🔗 Grab Image URLs:** Copy the direct, secure **image URL** for re-importing or technical use.
* **💾 Download Option:** Save any asset as a local file.
* **🔍 Focused Scanning:** Intelligently filters to show only real image files from `https://media-public.canva.com/`.
* **🔒 Privacy First:** Everything works entirely inside your browser (no external servers, no tracking).


</br>

## ⬇️ Install (Load unpacked)

1.  Download or clone this repo.
2.  Open your browser's extension page:
    * **Chrome / Edge / Brave** → navigate to `chrome://extensions`
3.  Toggle on **Developer mode** (usually in the top right corner).
4.  Click **Load unpacked**.
5.  Select this project folder (`Canva-Image-Hunter`).
6.  Pin **Canva Image Hunter** to your browser toolbar for easy access! 📌


</br>

## 🚀 How to Use

1.  Browse to any design or element page on **canva.com**.
2.  Click the **Canva Image Hunter** extension icon in your toolbar.
3.  Click **Refresh** in the popup to scan the page for all images.
4.  Find the Pro asset you want in the list and choose your action:
    * **Copy Image (PNG)** (to paste into your own design)
    * **Copy URL**
    * **Download**


</br>

## 📦 Build & Publish

1.  Make your changes and test them.
2.  Create a ZIP file of the extension folder (exclude `.git` and other dev-only files).
3.  Upload the zip file to the Chrome Web Store dashboard.
